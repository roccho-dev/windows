# Windows実装の継承先

source・配布・通常更新・新しいIssue/PRの窓口は [roccho-dev/resources](https://github.com/roccho-dev/resources) です。Windows Hostは引き続き維持します。

- [提供物と利用方法](https://github.com/roccho-dev/resources)
- [resourcesからのRelease](https://github.com/roccho-dev/resources/releases)
- [配置・Bindingの所有先](https://github.com/roccho-org/envs)
- [移行・退役の最終記録と保留案件の継承先](https://github.com/roccho-dev/resources/issues/25)
- [旧Git履歴・比較元・未merge差分・議論の保全物](https://github.com/roccho-dev/resources/releases/tag/windows-retirement-20261018)

このリポジトリは旧source・tag・Release・議論の履歴を保持します。新しい成果物の自動公開と更新提案はresourcesへ移管済みです。既存のGHCR名 `windows-own` / `windows-rent` は維持します。

保留案件の正式継承は、その機能の実装完了・検証成功・実Host採用を意味しません。未完条件と再開時の許可は継承先で確認してください。過去の手順・CI・Releaseの版を、現在の利用先や採用版へ読み替えないでください。

Windows Hostの廃止、既存の秘密・状態の移送、repoの削除は行いません。退役の判断・実Archive・取得確認の証拠は上の最終記録へ帰着します。
